# 🛍️ Magic Shop – One Stop Shopping Explorer

## 📌 Overview

**Magic Shop – One Stop Shopping Explorer** is a menu-driven Python application that helps users explore products across multiple shopping categories. The project provides a simple and interactive shopping experience by identifying product categories, displaying product images, supporting voice input, and redirecting users to relevant shopping websites.

This project was developed to strengthen my understanding of Python programming by applying core concepts to a real-world use case.

---

## ✨ Features

* 🛒 Menu-driven shopping application
* 🔍 Automatic product category detection
* 🖼️ Product image display using Pillow
* 🎤 Voice input using SpeechRecognition
* 🎵 Background music using Pygame
* 🌐 Opens shopping websites using Web Browser
* 📅 Displays date and time
* 💻 Beginner-friendly Python project


