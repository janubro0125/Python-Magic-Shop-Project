# Python-Magic-Shop-Project
A menu-driven Python shopping assistant built using core Python concepts.

## 📌 Overview
A menu-driven Python application that helps users explore products from different shopping categories.

## ✨ Features
- Product category detection
- Menu-driven interface
- Image display
- Voice interaction
- Background music
- Opens shopping websites
- Beginner-friendly Python project

## 🛠 Modules Used
- Python
- PIL (Pillow)
- pygame
- speech_recognition
- webbrowser
- datetime

## 🚀 How to Run
1. Install the required modules
2. Run the Python file
3. Follow the on-screen menu

## 📚 Learning Outcomes
- Functions
- Dictionaries
- Loops
- Conditional Statements
- Modules
- Exception Handling
